# Translation with Hugging Face Inference

Translate an English sentence to Urdu with `facebook/mbart-large-50-many-to-many-mmt` through `@huggingface/inference`.

## Run

```bash
npm install
npm start
```

Needs `HF_TOKEN` in the repository-root `.env` (see `../.env.example`).
