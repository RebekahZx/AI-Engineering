# Text to speech

Generate speech with `espnet/kan-bayashi_ljspeech_vits` and play it in an `<audio>` element.

## Run

```bash
npm install
npm start
```

Needs `HF_TOKEN` in the repository-root `.env` (see `../.env.example`).
