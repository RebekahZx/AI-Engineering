# Image-to-image with ControlNet

Restore and colourise an old black-and-white photo using a ControlNet image-to-image model, a text prompt and a negative prompt.

## Run

```bash
npm install
npm start
```

Needs `HF_TOKEN` in the repository-root `.env` (see `../.env.example`).
