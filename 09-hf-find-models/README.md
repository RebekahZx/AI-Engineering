# Find Hugging Face models

List text-to-image models on the Hub with `@huggingface/hub`, keep those with 2,000+ likes whose Inference API status is loadable, and sort them by likes.

## Run

```bash
npm install
npm start
```

Needs `HF_TOKEN` in the repository-root `.env` (see `../.env.example`).
